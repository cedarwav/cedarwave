# Cedar Wave Advisory — Brand & Content Package

Everything needed to build the site.

- **content-brief.md** — start here. Sitemap, page-by-page copy, palette, type, and logo usage rules, written as a build spec.
- **brand-guide.html** — open in a browser for the full visual brand guide (palette swatches, logo lockups in context, voice guidelines).
- **assets/** — logo files (icon, primary lockup, dark/reversed lockup) as SVG, ready to drop into the project.
